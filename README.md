	The objectives of the experiment will be to successfully accomplish the given tasks is to create 3 functions relating to the processing and manipulation of string and list data only through the use of basic Python operations, string methods, slicing, and sequence unpacking.

	"rotate_word()" is the first function presented and takes an input non-empty string variable moving its first character from its position as the starting index to the last index while ensuring that no other changes occur to any of the characters. An example of the expected output would be processing the word "Code" into the output string "odeC".

	The second function takes in 2 variables (x,y) with the second variable being the last name and the first variable comprising of the rest of the remaining name, i.e., first names and middle names. The code will strip any spaces within the names and join the two strings together using a period(.). Therefore if an input name such as "Ana" was defined for x and an input name of "De Leon" was defined for y, the expected output should be "ana.deleon".

	The last function has a similar operation to the first except it will apply its task on a list variable instead. Once a list variable has been placed as an input into the code, the first and last elements will be saved as a variable separately from the middle elements while the middle elements are saved as a list. The output will then be the first and last elements having switched their index placements, the first element now the last and the last element now the first while the middle elements remain untouched. An example process would be the list [a,b,c,d] becoming [d,b,c,a] once turned into an output.
